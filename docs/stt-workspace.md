# 녹음과 전사 검토 화면

클로바노트, Notta, Otter의 공식 기능 안내를 참고해 개인용 음성 노트에서 자주 쓰는 검토 흐름을 구현했다. 제품의 화면이나 브랜드를 복제하지 않고 현재 앱의 녹음·전사·요약 구조에 맞췄다.

## 녹음

- **녹음 시작**으로 브라우저 마이크를 연결한다. 실제 마이크 입력을 Web Audio 파형으로 표시한다.
- **일시정지 / 녹음 계속**을 지원한다. 녹음 시간과 북마크 시점은 일시정지 시간을 제외한다.
- **이 순간 표시**로 이름과 시간을 남긴다. 녹음 파일이 서버에 저장되면 북마크를 별도 API에 저장한다.
- **녹음 종료하고 전사**를 누르면 마이크와 AudioContext를 해제하고 자동으로 전사를 시작한다.
- **AI 요약도 생성**을 해제하면 LLM 없이 전사까지만 완료한다. 저장된 전사에서 나중에 **요약 생성**을 실행할 수 있다.
- 녹음을 취소하거나 마이크 권한 요청을 취소하면 뒤늦게 생성된 스트림까지 해제한다. 파일 전송 실패 시 녹음 미리 듣기와 재시도를 유지한다.

녹음은 HTTPS 또는 localhost와 마이크 권한이 필요하다. WebM/Opus, MP4/AAC, OGG 중 브라우저가 지원하는 형식을 선택한다. 음성은 최대 24MB이며 23MB에 도달하면 자동으로 종료·전사한다. Safari/모바일 실제 기기 검증은 별도로 필요하다.

## 전사 검토

- 원본 음성의 **±5초**, **0.75~2배속**, **재생 문장 따라가기**를 제공한다. 발언을 편집 중이면 자동 스크롤을 멈춘다.
- 시간 버튼으로 해당 발언을 듣는다. 오디오 API는 `Resource` 응답으로 HTTP Range 부분 요청을 지원한다.
- **이 노트에서 검색**은 정규식을 해석하지 않는 부분 문자열 검색이다. 안전한 텍스트 노드로 일치 부분을 표시하고 위·아래 버튼이나 Enter/Shift+Enter로 이동한다. 검색과 화자 필터를 함께 적용한다.
- 북마크는 재생 중에도 추가·삭제할 수 있다. 다시 노트를 열어도 서버에서 시간순으로 불러온다. 저장 실패 시 브라우저 세션에 남기고 같은 ID로 재시도한다.
- TXT 내보내기는 현재 검색·화자 필터를 적용한 전사를 저장한다. SRT 내보내기는 그중 시작·종료 시간이 있는 발언만 사용한다. 시간이 없는 기존 전사에서는 SRT 버튼을 비활성화한다.
- AI 요약은 핵심 요약·결정 사항·할 일·추가 확인으로 구분해 표시하고 복사하거나 Markdown 파일로 저장할 수 있다. 기존 일반 텍스트 요약도 표시한다.
- 모바일에서도 노트 목록에 접근할 수 있다. 화자 관리와 개별 발언 편집은 기존 기능을 유지한다.

현재 Whisper 경로는 녹음이 끝난 후 전사하는 방식이다. 실시간 자막이나 자동 화자 분리를 새로 제공하지 않는다. 자동 화자 구분이 필요하면 기존 Google 모드를 선택한다. 요약 모델·키 설정 여부는 서버의 공개 상태 API에서 읽으며, 키 값은 브라우저에 전달하지 않는다.

## 검증

`node scripts/test-ui.cjs`는 격리된 API 서버와 Chrome 가상 마이크로 녹음·일시정지 시간·파형 수명·북마크 저장/재시도·전사 검색·재생 동기화·SRT·전사만 처리·기존 편집 기능·모바일 화면을 검사한다. 스크린샷은 `build/ui-test`에 생성된다. 외부 STT나 요약 API를 호출하지 않는다.

서버 검증은 Groq 요청 규격·오류·키 비노출, 분할 요약, 북마크 저장·입력 제한, 오디오 Range 재생을 포함한다. 저장소 검증은 `RUN_STORAGE_TESTS=true`와 `compose.test.yaml`의 고정된 격리 DB 포트만 사용한다. 실제 STT 정확도와 무료 LLM의 한국어 품질·속도는 API 키를 연결한 뒤 원문과 대조해야 한다.
